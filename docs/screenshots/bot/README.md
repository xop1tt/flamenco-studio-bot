# Скриншоты Telegram-бота

Интерфейс Telegram нельзя снять автоматически без входа в реальный аккаунт,
поэтому эти скриншоты делаются вручную. Положите файлы сюда с указанными
именами и раскомментируйте блок «Telegram Bot» в разделе «Screenshots»
корневого `README.md`.

## Подготовка

- Снимайте **тестового бота с демо-данными**, а не production: в кадр не
  должны попасть реальные имена, телефоны, платежи и чаты.
- Демо-данные: 4–6 занятий на ближайшую неделю в разных направлениях,
  баланс 2–3 занятия, одна запись (через админ-меню бота или напрямую в
  тестовой БД).
- Telegram Desktop, одна и та же ширина окна для всех кадров (например,
  окно ~ 900×1000), светлая тема Telegram. Обрежьте кадр по области чата —
  без списка чатов, своего аватара и номера телефона.
- Формат PNG.

## Кадры

| Файл | Что показать | Как получить |
|---|---|---|
| `bot-start.png` | Приветствие и главное меню (reply-клавиатура) | Отправить `/start` |
| `bot-schedule.png` | Список ближайших занятий с фильтром по направлениям | Нажать «🗓 Записаться» |
| `bot-booking.png` | Подтверждение записи: «Вы записаны ✓», баланс, срок отмены | В списке нажать на занятие, до которого больше 24 часов |
| `bot-my-classes.png` | Предстоящие записи и баланс | Нажать «📖 Мои занятия» |
| `bot-packages.png` | Абонементы и цены | Нажать «💳 Абонементы» |
| `bot-profile.png` | Профиль: имя, телефон, баланс | Нажать «👤 Профиль» |

Необязательно, если нужен ещё один кадр: «💃 О студии» (`bot-about.png`)
или «💬 Помощь» (`bot-help.png`).

Перед коммитом проверьте, что на изображениях нет реальных персональных
данных, токенов и ссылок на оплату.
